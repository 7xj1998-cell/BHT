# Lệnh và nút BHT 1.0.20

| Công việc | Nút / lệnh | Kết quả |
| --- | --- | --- |
| Xuất báo cáo | Tuyến & báo cáo → Xuất báo cáo biển báo Excel | XLSX gồm Tổng hợp và Danh sách biển; mỗi mặt một dòng, đủ biển phụ |
| Kiểm tra cùng cụm | ID hồ sơ / Mặt trong cụm trong Excel | Các dòng 1/2, 2/2 giữ cùng tim, lý trình, đoạn/gói |
| Đọc Offset | Lệch tim tuyến (m) trong Excel | Khoảng cách mặt bằng từ vị trí hồ sơ đến tim dùng tính lý trình |
| Nạp bảng đoạn | Nạp Excel / bảng BHT / BHTGOITHAU / BHTNAPDOAN | Xem trước XLSX, chuyển `.bhtseg`, nạp đồng thời bảng |
| Gán tim cho đoạn | Xem đoạn / gán tim đường, tim rãnh / BHTTIMDOAN | Chọn tim riêng cho một hoặc nhiều đoạn |
| Phân đoạn | Gán đoạn / gói theo tim của đoạn / BHTPHANDOAN | Tính theo tim từng đoạn, có Undo |
| Tính toàn bộ | Tính lý trình tất cả hồ sơ / BHTLYTRINH | Giữ tim riêng của đoạn, cọc giữ số khảo sát |
| Chuyển dự án | BHTXUATDUAN / BHTNAPDUAN | `.bht` chứa dữ liệu và hình học; `.bhtseg` chỉ chứa bảng đoạn |

Gõ BHTHELP để xem các lệnh CAD khác. Giao diện báo rõ số hồ sơ/cụm và số mặt sau xuất. Xuất Excel không tự tính lại lý trình.
