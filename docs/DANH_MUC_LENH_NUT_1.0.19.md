# Lệnh và nút BHT 1.0.19

| Công việc | Nút / lệnh | Cách dùng |
| --- | --- | --- |
| Nạp bảng đoạn | Nạp Excel / bảng BHT / BHTGOITHAU / BHTNAPDOAN | Chọn .xlsx hoặc .bhtseg, xem trước và áp dụng; Excel bắt buộc chuyển sang .bhtseg |
| Xem/sửa đoạn và gán tim | Xem đoạn / gán tim đường, tim rãnh / BHTTIMDOAN | Chọn tim ở từng dòng, hoặc chọn nhiều dòng rồi gán cùng tim |
| Lưu mẫu nhập | Lưu bảng Excel mẫu | Sửa bằng Excel; giữ tên cột, không xuất lại TSV |
| Phân đoạn | Gán đoạn / gói theo tim của đoạn / BHTPHANDOAN | Tính lý trình và phân theo các tim đã gán; có Undo |
| Quyết định trường hợp trùng | Chọn đoạn / gói cho hồ sơ / BHTGANDOAN | Nhập mã đoạn; X bỏ gán tay để phân lại |
| Tính riêng | Hồ sơ → Tính lý trình hồ sơ này | Dùng tim của đoạn đã gán; cọc giữ số Km/H |
| Tính chung | Tuyến → Tính lý trình tất cả hồ sơ / BHTLYTRINH | Giữ tim riêng của đoạn, các hồ sơ khác theo phương pháp chung |
| Chuyển cả dự án | BHTXUATDUAN / BHTNAPDUAN | .bht chứa hình học, hồ sơ, bảng đoạn và tim. .bhtseg chỉ là bảng đoạn |

Các lệnh đặt biển, cọc, nhãn và báo cáo của 1.0.18 giữ nguyên. Gõ BHTHELP để xem toàn bộ lệnh.
