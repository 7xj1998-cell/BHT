# Lệnh và nút BHT 1.0.24

| Thao tác | Lệnh / nút | Cách dùng |
|---|---|---|
| Chọn đoạn cho hồ sơ | BHTGANDOAN | Chọn biển, chọn dòng trong bảng, kiểm tra tên gói, khoảng Km, phía đường rồi gán |
| Bỏ gán | Bỏ gán đoạn trong bảng chọn | Xóa đoạn/gói hiện tại; Undo khôi phục |
| Gán tim riêng | BHTTIMDOAN | Chọn tim đường, tim rãnh hoặc tuyến khác cho từng đoạn |
| Phân đoạn toàn bộ | BHTPHANDOAN | Tính theo các tim đã gán; giữ lựa chọn thủ công; trường hợp mơ hồ cần chọn |
| Tính lý trình hồ sơ này | Nút trên tab Hồ sơ | Tính lại và cập nhật đoạn phù hợp với tim, Km và phía đường |
| Tính lý trình toàn bộ | BHTLYTRINH | Cập nhật lý trình theo phương pháp đang dùng |
| Tính lại theo tim | BHTTINHTHEOTUYEN | Dùng tim đang chọn; cập nhật phân đoạn từ kết quả mới |
| Biển tên đường | I.449 → Nội dung biển | Ô trên ĐƯỜNG, ô dưới tên đường; áp dụng rồi Vẽ/cập nhật ký hiệu |
| Nạp/lưu bảng đoạn | BHTGOITHAU | Nạp Excel hoặc .bhtseg; bảng lưu trong dự án .bht |
| Nạp tim và chọn loại | BHTTUYENTDT / BHTTUYEN | Chọn đúng loại trước khi tính |
| Sửa loại tim | BHTSUATUYEN | Thay thông số, sau đó tính lại |
| Xem/xóa mốc | BHTDSMOC | Bảng chọn mốc; Undo khôi phục xóa |

Phía đường trong bảng đoạn và phía so với tim rãnh là hai thông tin khác nhau. BHT giữ phía đường đã nhập; nếu sai, sửa tại hồ sơ hoặc chủ động gán đoạn thủ công.
