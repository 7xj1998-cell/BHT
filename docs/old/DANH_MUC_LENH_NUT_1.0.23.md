# Lệnh và nút BHT 1.0.23

| Bước / thao tác | Lệnh | Cách dùng |
|---|---|---|
| 1. Nạp báo hiệu | BHTNAPBAOHIEU | Nạp điểm, hồ sơ, ảnh, bảng đoạn để tính theo tim đích |
| 2. Nạp tim | BHTTUYENTDT / BHTTUYEN | Chọn hình học; hộp nhập cho chọn Tim đường, Tim rãnh hoặc Tuyến khác |
| Sửa tuyến | BHTSUATUYEN | Chọn dòng tim rồi mở hộp sửa ID, loại tim, lệch tối đa và ngoại suy; nhận dấu phẩy/chấm |
| Điểm đầu và chiều | BHTROUTESTART / BHTROUTEREVERSE | Xác định đầu/chiều tăng lý trình; kiểm tra lại mốc sau thay đổi |
| 3. Đọc mốc TDT | BHTDOCCOCTDT | Đọc, kiểm tra và xác nhận cọc gốc trong profile TDT |
| Thêm mốc | BHTMOCKM | Khai báo mốc đã biết hoặc điểm gãy Km |
| Bảng mốc | BHTDSMOC | Chọn dòng xem vị trí trên CAD; Ctrl/Shift chọn nhiều mốc rồi xóa; Undo khôi phục |
| 4. Tính lại / kiểm tra | BHTTINHTHEOTUYEN / BHTROUTEDIAG / BHTDIMTIM | Dùng tim đang chọn, kiểm tra mốc/phạm vi và đo DIM |
| 5. Trình bày | BHTHUONGBIEN / BHTSAPNHAN | Hướng mặt biển và nhãn |
| 6. Xuất | Excel / BHTXUATDUAN | Xuất kết quả đã tính; .bht giữ bảng đoạn đã nạp vào DWG |
| Đoạn / gói thầu | BHTGOITHAU / BHTTIMDOAN / BHTPHANDOAN | Nạp bảng, gán tim riêng, phân đoạn |
| Nạp nguyên dự án | BHTNAPDUAN | Giữ tim/mốc/phương pháp nguồn; dùng DWG chưa có BHT |

Xóa mốc trong bảng chỉ bỏ mốc BHT đã khai báo; cọc TDT gốc được giữ. Mốc tự động quản lý tại hồ sơ cọc. Sau khi đổi thông số tim hoặc xóa mốc, tính lại lý trình trước khi xuất. Các lệnh khác: BHTHELP.
