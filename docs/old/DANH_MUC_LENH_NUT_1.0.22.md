# Lệnh và nút BHT 1.0.22

| Bước | Lệnh / nút | Cách dùng |
|---|---|---|
| 1. Nạp báo hiệu | BHTNAPBAOHIEU | Nạp điểm, hồ sơ, ảnh, bảng đoạn; tính lại theo tim đích |
| 2. Chọn tim đoạn | BHTTUYENTDT / BHTTUYEN | Nạp hình học; chọn dòng tim, sửa loại tim, xác nhận điểm đầu/chiều |
| 3. Xác nhận mốc Km | BHTDOCCOCTDT / BHTMOCKM / BHTDSMOC | Đọc mốc TDT hoặc thêm mốc đã biết; xem/xóa mốc |
| 4. Tính lại/kiểm tra | BHTTINHTHEOTUYEN / BHTROUTEDIAG / BHTDIMTIM | Dùng tim đang chọn; kiểm tra phạm vi, mốc và DIM |
| 5. Trình bày | BHTHUONGBIEN / BHTSAPNHAN | Hướng biển và nhãn |
| 6. Xuất hồ sơ | Excel / BHTXUATDUAN | Báo cáo đủ mặt; .bht giữ cả bảng đoạn đã lưu |
| Đoạn/gói thầu | BHTGOITHAU / BHTTIMDOAN / BHTPHANDOAN | Nạp bảng, gán tim riêng, phân đoạn |
| Nạp nguyên dự án | BHTNAPDUAN | Giữ tim, mốc, bảng đoạn và kết quả nguồn; dùng DWG chưa có BHT |

Phương pháp theo cọc nằm trong mục bổ sung. Tim TDT không tự lấy Km/H hồ sơ cũ làm mốc. Nút cần chọn tim chỉ bật khi chọn một dòng tim. Các lệnh khác: BHTHELP.
